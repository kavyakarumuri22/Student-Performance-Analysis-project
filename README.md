# Student Performance Analysis

## Pluto Academy Data Analytics Internship – Project 2

### Project Overview
This project analyzes student performance data to identify the factors affecting academic scores, including gender, parental education, lunch type, and test preparation. The analysis provides insights to help improve student outcomes.

### Objectives
- Explore and clean the dataset
- Analyze factors affecting student performance
- Identify at-risk students
- Perform correlation analysis
- Create visualizations
- Generate recommendations for improving academic performance

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Project Files
- Student_Performance_Analysis.ipynb

### Key Insights
- Examined the impact of parental education.
- Compared performance based on test preparation.
- Analyzed gender-wise performance.
- Identified at-risk students.
- Suggested recommendations for improving academic performance.
